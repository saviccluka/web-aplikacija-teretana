# Fit & Strong — Gym Website

A simple, responsive multi-page website for a fictional gym called **Fit & Strong**, built with plain HTML, CSS, and JavaScript (no frameworks, no build tools).

## About

This project is a static website showcasing a gym's services, team, and facilities. It includes a home page, an "About Us" page, a services page, a photo gallery, and a contact page — all styled with a consistent, mobile-friendly layout.

## Pages

| File | Description |
|---|---|
| `index.html` | Home page — hero section, key features ("Why choose us"), and member testimonials |
| `o-nama.html` | About Us — information about the gym and its story |
| `usluge.html` | Services — overview of gym services and programs |
| `galerija.html` | Gallery — photos of the gym and its facilities |
| `kontakt.html` | Contact — contact information and location |

## Features

- 🏋️ Clean, modern layout tailored for a gym/fitness business
- 📱 Responsive design with a mobile hamburger menu
- 💬 Testimonial slider on the home page
- 🖼️ Image gallery section
- ✉️ Contact page with address, phone, and email details

## Tech Stack

- **HTML5** — page structure and content
- **CSS3** — styling and responsive layout
- **JavaScript (vanilla)** — interactivity (navigation, sliders)
- Google Fonts (Montserrat, Open Sans)

## Getting Started

No build steps or dependencies are required — this is a static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/saviccluka/web-aplikacija-teretana.git
   ```
2. Open the project folder:
   ```bash
   cd web-aplikacija-teretana
   ```
3. Open `index.html` directly in your browser, or serve it locally, e.g.:
   ```bash
   npx serve .
   ```

## Language Note

The site content (text, navigation, labels) is written in Serbian, as it's intended for a Serbian-speaking audience.
